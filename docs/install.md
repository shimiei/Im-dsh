# 安装与首次连接

产物：`imdsh/dist/IMDSH-unsigned.ipa`（**未签名**，约 700 KB）。
它不包含任何证书，也不可能包含——签名必须由你真机上的工具完成。

## 1. 三种装机方式（任选一种）

### A. TrollStore（最简单）
1. 手机已装 TrollStore（需要对应系统版本的安装方式，自行解决）；
2. AirDrop / 文件 App 把 `IMDSH-unsigned.ipa` 传到手机；
3. 在文件 App 里点它 → 分享 → **TrollStore** → Install。
   TrollStore 会做 ad-hoc 签名并永久安装，**不会 7 天过期**。

### B. ESign / Feather / iLoader（有自己的证书）
1. 把 ipa 传到手机，用 ESign「导入」；
2. 在 ESign 的「签名」里选择你的 p12 + mobileprovision，`Bundle ID` 保持 `com.imdsh.app`；
3. 签名后安装。免费开发者账号 7 天过期，付费证书 1 年。

### C. AltStore / SideStore（用 Apple ID 自签）
1. 电脑装 AltServer，手机装 AltStore；
2. AltStore → 我的 App → `+` → 选 ipa；
3. 需要定期刷新（同一 Wi-Fi 下 AltServer 会自动续）。

> 已测试的路径是「clang 交叉编译 + 未签名 ipa」这一段；签名工具本身的行为由各自工具决定。
> 如果装完**闪退**，99% 是签名工具没有正确嵌入 provisioning profile，或者 bundle id 与
> profile 里的 App ID 不匹配。

## 2. 电脑侧准备（一次即可）

1. DSH 里确保 **dsh-webim 插件已更新到本仓库的版本**（带配对码能力），并**重启 DSH**
   （插件不会热加载新路由；重启后 `curl http://<主机>:3081/__webim/ping` 应有 `ok: true`）；
2. 打开 DSH 的 **设置 → 远程接入**，确认网关在监听（默认 `3081`）；
3. 在「设备配对」卡片里点 **生成配对码** —— 得到形如 `7K4M-QP2X-9FTW` 的码，
   默认 30 天有效（可设永久）。**一个码只能给一台设备用。**

## 3. 手机侧首次连接

1. 打开 IMDSH → 填 **地址**：
   - 同一局域网：`192.168.1.20:3081`（写成 `http://192.168.1.20:3081` 也行，端口必须是网关端口）；
   - 跨网络：用 Cloudflare 隧道的域名（`https://xxx.trycloudflare.com`，此时不要带端口）；
   - 不支持只写主机名不带端口（默认端口不是 3081，见下方排错）。
2. 填 **配对码**（大小写不敏感，连字符可省）；
3. 点 **开始配对**。成功后会直接进取会话列表，并把这台设备记进主机的「已配对设备」。

配对记录了两个东西：
- **deviceId**：本机 Keychain 里的稳定 UUID（重装 App 会变，变了就要重新配对）；
- **deviceToken**：32 字节长效凭据，Keychain 保存，随请求以 `Cookie: webim_device=…` 发出。

## 4. 排错

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 配对页提示「连不上主机」 | 地址/端口错、手机不在同一网段、电脑防火墙拦了 3081 | 手机浏览器直接开 `http://<地址>/__webim/ping`，能出 JSON 才是通的 |
| 「配对码无效」 | 码打错、或已被用掉 | 回电脑看「设备配对」卡片里的码列表，重新生成 |
| 「这个码已经绑定其它设备」 | 一码一机 | 生成新码；旧设备不受影响 |
| 「配对码已过期」 | 超过有效期 | 重新生成 |
| 配对成功但列表一直转圈 | 网关连不上上游 DSH，或 DSH 未启动 | 电脑上开 DSH 的网页版确认能进；看 DSH 日志 |
| 用一会就「连接中断，正在重试…」 | Wi-Fi 切换/后台休眠 | 会自动重连；一直不动就下拉刷新或切一下页面 |
| 想撤销某台设备 | — | 电脑设置页「设备配对」列表点吊销，或 App 设置 → 已配对设备 → 吊销 |
| 换了手机/重装后配不上 | deviceId 变了，旧码已绑定 | 电脑上吊销旧设备 + 生成新码 |

## 5. 安全说明

- device token 等效于「这台设备的登录态」：能读会话、能发消息（会真的驱动 Agent）。
  **只在你信任的网络里配对**，明文 HTTP 下 token 是可被嗅探的——公网请用 https 隧道。
- 吊销立即生效（服务端删记录，不依赖客户端配合）。
- App 不保存 DSH 的任何浏览器凭据；网关自己铸造 `dsh-auth-*` Cookie 转发给上游，
  这些 Cookie 不出主机。
- App 不向任何第三方发送数据；没有统计 SDK。
